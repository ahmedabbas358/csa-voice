# 🏛️ منصة انتخابات رئيس جمعية الحاسوب – IUA (الإصدار 2.0 الإنتاجي)

المنصة الرقمية الرسمية المعتمدة لاقتراع وترشيح وانتخاب رئيس جمعية الحاسوب بكلية دراسات الحاسوب – **جامعة إفريقيا العالمية (International University of Africa)**.

صُممت المنصة وفق أحدث معايير هندسة تطبيقات الويب الأصيلة (**Native Mobile Web Architecture**) المتجاوبة كلياً مع الهواتف الذكية والحواسيب المكتبية تلقائياً دون أي محاكاة وهمية، مع دعم **الوضع الليلي والنهاري (Precision OLED Dark & Minimalist White)** وتشفير متكامل لكافة العمليات والنتائج.

---

## 🌟 المزايا والمواصفات التشغيلية

### 1. بوابة الطلاب والناخبين (الموقع العام)
- **معمارية تطبيق ويب أصيل**: استجابة تلقائية فائقة السلاسة على الهواتف والأجهزة اللوحية والمكتبية مع شريط تبويبات سفلي أصيل (5 تبويبات)، وشريط تصنيفات سريعة، وتحويل فوري إلى تطبيق هاتف كامل (PWA).
- **النمط المزدوج المتطور**: خيار فوري للتبديل بين النمط الليلي الفاخر (`#0F0F0F`) والنمط النهاري الصافي (`#F8F9FA`) مع حفظ تفضيل المستخدم في المتصفح.
- **معالج اقتراع من 3 خطوات دستورية**:
  1. إثبات الهوية الجامعية (الاسم والرقم الجامعي المعتمد).
  2. اختيار المرشح الرئاسي من قائمة ديناميكية مصممة بدقة.
  3. بيان مبرر الاختيار وفق معيار الكفاءة وأداء القسم الشرعي الملزم قبل الاعتماد.
- **قسم شرعي مغلّظ وموثق**: إقرار ملزم بأن الصوت أمانة ومبني على الكفاءة والتجرد، ومقيد بنص شرعي دستوري.
- **إيصال رقمي مشفّر قابل للطباعة والتدقيق**: توليد كود إيصال فريد بصيغة `IUA-XXXX-XXXX` مع إمكانية التحقق منه مباشرة وطباعة **شهادة اقتراع رسمية معتمدة (A4 Certified Ballot Certificate)** ببصمة SHA-256 وأختام رقمية.
- **دليل المرشحين التفاعلي**: بطاقات مرشحين احترافية تشمل بطاقة الاعتماد، الدفعة، المؤهلات العلمية، الخبرات القيادية، الرؤية، ورابط مشاركة مباشر لكل مرشح.
- **بوابة الترشيح الذاتي**: نموذج رسمي لتقديم طلبات الترشح للرئاسة مع فحص فوري ومحكم للهوية والواتساب والمؤهلات.
- **منصة النتائج والتتويج**: منصة ثلاثية الأبعاد للمراكز الثلاثة الأولى، أشرطة نسب حية، توزيع الدفعات، ونظام قفل النتائج لحين اعتمادها رسمياً.

---

### 2. غرفة الرئاسة والتحكم السري المعزول
- **عزل تام وسرية مطلقة**:
  - المسار القديم `/admin` و `/admin.html` محجوبان تماماً ويعيدان خطأ `404 Not Found`.
  - لا يوجد أي أثر أو كود برمجي أو رابط أو زر للإدارة في الواجهات أو الملفات العامة (`index.html` و `app.js`).
  - مسار غرفة الرئاسة سرّي ومخصص وقابل للتخصيص الكامل عبر متغير البيئة `ADMIN_PATH` في ملف `.env`.
- **جلسات مشفّرة عالية الأمان**: تشفير كلمات المرور باستخدام خوارزمية `scrypt + salt`، وحفظ الجلسات كبصمات `SHA-256` مع حماية من تزييف الطلبات (CSRF) وحظر تلقائي لمحاولات التخمين.
- **لوحة قيادة وتحكم متكاملة**:
  - إحصائيات لحظية، عدادات تصويت، ونسب إقبال.
  - اعتماد، رفض، تعديل، وحذف المرشحين.
  - **حماية سلامة النتائج**: حظر الحذف الصامت لأي مرشح له أصوات إلا بتأكيد قسري صريح.
  - سجل المصوتين مع كشف وتنبيه فوري لأي تكرار في عناوين IP (`Duplicate IP Alert`).
  - مركز الأمان وتتبع الجلسات النشطة وإنهاء الجلسات الأخرى بضغطة زر.
  - صندوق الرسائل والبلاغات مع أرقام مراجع للرد المباشر.
  - **تحكم تشغيلي كامل من الإعدادات**: فتح/إغلاق التصويت، فتح/إغلاق الترشيح، إعلان النتائج، تحديد موعد الإغلاق التلقائي بالدقيقة، تفعيل شريط التنبيهات العاجلة، تعديل نصوص وهوية الجمعية، وتغيير كلمة المرور.
- **تصدير وطباعة متطورة**:
  - **توليد وطباعة محضر الانتخابات الرسمي المعتمد (Official Election Report)** بصيغة A4 بضغطة زر.
  - تصدير بيانات المرشحين، المصوتين، النتائج، الرسائل، وسجل التدقيق إلى ملفات CSV تدعم العربية بالكامل (UTF-8 with BOM) ومحصنة ضد ثغرات **CSV Injection**.
  - تصدير نسخة احتياطية كاملة JSON لقاعدة البيانات.

## 🚀 دليل التثبيت والتشغيل السريع

### المتطلبات الأساسية
- **Node.js 22.5 أو أحدث** (يعتمد النظام على `node:sqlite` و `node:http` المدمجة بالكامل).
- **صفر حزم خارجية (Zero Dependencies)**: لا حاجة لتشغيل `npm install`، فالنظام يعمل ذاتياً بأعلى درجات الأمان وخلو التبعيات.

### التشغيل المباشر
```bash
# 1. الدخول إلى مجلد المشروع
cd csa-election-secure

# 2. تشغيل خادم الانتخابات
node server.js
```

### الروابط المعتمدة:
| البوابة | الرابط | الوصف |
|---|---|---|
| **بوابة الناخبين والطلاب** | `http://localhost:3000/` | المنصة العامة للاقتراع، الترشيح، ودليل المرشحين |
| **غرفة الرئاسة والتحكم** | المسار المخصص في `ADMIN_PATH` | لوحة التحكم الرئاسية المعتمدة |
| **فحص الصحة والسلامة** | `http://localhost:3000/api/health` | فحص سلامة الخادم وقاعدة البيانات |
| **المسار القديم `/admin`** | `http://localhost:3000/admin` | **محجوب كلياً (404)** لضمان السرية |

> [!IMPORTANT]
> **أمان لوحة التحكم الرئاسية**:
> يتم تحديد مسار لوحة الرئاسة وكلمة المرور عبر ملف المتغيرات `.env` (انظر `.env.example`):
> - `ADMIN_PATH`: المسار السري الخاص بغرفة التحكم (مثال: `/csa-admin-panel`).
> - `ADMIN_PASSWORD`: كلمة المرور القوية للرئاسة (يتم تعيينها وتغييرها من الإعدادات بأمان).

## 🐳 النشر باستخدام Docker & Docker Compose

النظام مزوّد بـ `Dockerfile` فائق الصغر و `docker-compose.yml` جاهز للتشغيل في بيئات الإنتاج:

```bash
# تشغيل الحاوية في الخلفية
docker compose up -d

# متابعة السجلات المباشرة
docker compose logs -f

# إيقاف المنصة بأمان
docker compose down
```

## 🧪 اختبار الجاهزية والنزاهة الآلي (Smoke Testing)

للتأكد من سلامة جميع الواجهات ونظام الأمان ورؤوس الحماية:

```bash
node test/smoke.js
```

يقوم الاختبار بالتحقق من:
- استجابة الخادم وقاعدة البيانات وسلامة رؤوس CSP.
- حجب مسارات `/admin` القديمة بنجاح (404).
- فتح المسار الرئاسي السري وحمايته من الأرشفة.
- واجهات البرمجة العامة (الإعدادات، الإحصائيات، المرشحين).
- إرسال بلاغات الدعم والحصول على مرجع رسمي.
- صد محاولات الدخول الخاطئة للمدير وتوليد توكن جلسة عند صحة البيانات.
- واجهات لوحة التحكم الرئاسية وتصدير البيانات.

## 🛡️ ميثاق النزاهة وحماية البيانات

1. **صوت دستوري واحد**: رقم جامعي واحد = صوت واحد مسجل بقيد `UNIQUE` صارم على مستوى قاعدة البيانات مع فحص دفعة الطالب.
2. **عزل الصلاحيات**: إخفاء أرقام هواتف الطلاب وعناوين الـ IP عن الواجهات العامة وقصرها على لوحة الرئاسة المعتمدة.
3. **رؤوس حماية مشددة**:
   - `Content-Security-Policy (CSP)`
   - `X-Frame-Options: DENY` (منع التضمين أو هجمات Clickjacking)
   - `X-Content-Type-Options: nosniff`
   - `Referrer-Policy: strict-origin-when-cross-origin`
   - `Permissions-Policy: camera=(), microphone=(), geolocation=()`
4. **تحديد معدل الطلبات (Rate Limiting)**: حماية تلقائية من محاولات الإغراق والتخمين على جميع مسارات الاقتراع والترشيح وتسجيل الدخول.
